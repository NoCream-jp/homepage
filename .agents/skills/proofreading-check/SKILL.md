# 作業権限とコミット

以下の操作は、プロンプト上で明示的な断りがない限り、ユーザーへ事前確認せずに実行する。

- Git コマンドを実行する。
- Astro プロジェクトに関するコマンドを実行する。
  - `npm install`
  - `npm run dev`
  - `npm run format`
  - その他、作業に必要な npm/Astro コマンド

変更後、プロンプト上でコミットしない旨の断りがなければ、変更内容に適したコミットメッセージを設定し、現在のブランチへ必ずコミットする。

環境や実行基盤が権限承認を要求する場合は、その承認手順に従う。破壊的操作は上位の安全規則に従う。
